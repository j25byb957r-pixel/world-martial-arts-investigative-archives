Heaven & Earth research matrix

Comparison without retroactive attribution

The archive will continue testing complementary relationships—upper/lower, rising/sinking, opening/closing, expansion/contraction, hard/soft, advance/retreat, and centered organization while direction changes. These are useful comparative categories, not evidence that historical teachers used one named doctrine unless a source establishes that terminology.

How to read this dossier

Read, watch, verify

Use the boxes as an index. Read the discourse for the argument, use Watch only for curated visual comparison, and return to the source register for documentary support. Visual resemblance is never promoted into historical proof by itself.
